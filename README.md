# 자바 기반 고양이 자동 급식기 시스템 프로토타입 (Cat Automated Feeder)

자바 객체지향 프로그래밍과 파일 입출력을 바탕으로 구현한 텍스트 기반 자동 급식 제어 프로그램입니다.  
2024년 2학년 2학기 `객체지향 프로그래밍` 강의에서 가산점 획득을 위해 수행한 자율 과제물로, 클래스 설계, 데이터 저장, 급식량 계산, 시리얼 통신 인터페이스 흐름을 함께 다뤘습니다.

> 이 저장소는 2024년 자율 과제물 보고서를 바탕으로,  
> 당시 로컬 환경에 보관하던 소스코드를 **포트폴리오 및 코드 아카이브 목적**으로  
> 개인 GitHub 저장소에 옮겨 정리한 버전입니다.  
> 본 프로젝트는 Git 기반 협업으로 진행된 프로젝트가 아니며, 1인으로 기획 및 구현했습니다.  
> 또한 단기간 내에 수행한 프로토타입 과제로, 아두이노 하드웨어와의 실제 물리적 연동까지는 진행하지 않았고  
> 코드 수준에서 시리얼 통신 인터페이스를 설계해보는 데 의미를 두었습니다.

## 1. 프로젝트 개요

- **진행 기간**: 2024.12 (약 1주)
- **프로젝트 형태**: 1인 개인 프로젝트
- **개발 배경 및 목적**
  - 실제 반려묘를 키우며 느낀 주기적이고 정량적인 급식 관리의 필요성을 바탕으로 기획했습니다.
  - 자바의 클래스 설계, 조건문, 반복문, 메서드 분리 등 객체지향 기초 문법을 직접 적용해보고자 했습니다.
  - 파일 입출력을 통해 데이터를 저장·불러오는 구조를 구현하고, 향후 하드웨어 제어로 확장 가능한 프로그램 흐름을 구상하고자 했습니다.

## 2. 기술 스택

- **개발 언어**: Java (JDK 17)
- **운영체제 환경**: Windows 10 / 11
- **개발 도구**: Eclipse
- **데이터 저장 방식**: Java Object Serialization, Local File I/O
- **외부 라이브러리**: jSerialComm
- **주요 API / 클래스**
  - `ObjectOutputStream`, `ObjectInputStream`
  - `FileInputStream`, `FileOutputStream`
  - `Math.pow()`
  - `SerialPort`

---

## 3. 실행 방법

### 1) 실행 전 준비

- Java 개발 환경(JDK 17 이상)이 필요합니다.
- 로컬 파일 저장을 위해 실행 폴더에 쓰기 권한이 필요합니다.
- 시리얼 통신 기능을 확인하려면 Windows 환경과 포트 인식 가능한 장치가 필요합니다.

### 2) 실행 방법

1. 프로젝트 소스코드를 다운로드합니다.
2. 메인 실행 파일인 `Cat_Feeding.java`를 실행합니다.
3. 콘솔 메뉴에 따라 기능을 테스트합니다.

### 3) 주요 사용 흐름

- **고양이 정보 입력**: 이름, 체중, 활동량 등의 정보를 입력
- **급식량 계산**: 입력된 정보를 바탕으로 하루 적정 사료량 계산
- **데이터 저장 및 불러오기**: 종료 후에도 로컬 파일에 정보 유지
- **시리얼 통신 메서드 호출**: 배식 명령을 외부 장치로 전달하는 구조 확인

## 4. 시스템 아키텍처 및 핵심 포인트

### 시스템 구조

```text
사용자 입력
   ↓
고양이 정보 객체 생성 / 수정
   ↓
급식량 계산 로직 수행
   ↓
파일 저장 / 불러오기
   ↓
(선택) 시리얼 통신 메서드 호출
   ↓
외부 장치 제어를 위한 확장 가능 구조
```

### 핵심 포인트

- **객체지향 기반 데이터 모델링**
  - 고양이 정보를 객체 단위로 관리하도록 구성
  - 입력값, 계산 로직, 저장 기능을 역할별로 나누어 설계

- **파일 저장 구조 구현**
  - `ObjectOutputStream`, `ObjectInputStream`을 활용해 데이터 저장
  - 프로그램 종료 후에도 로컬 파일에서 정보를 다시 불러올 수 있도록 구성

- **급식량 계산 로직**
  - 체중 기반 기초 연산과 활동량 가중치를 반영해 급식량 계산
  - 단순 입력/출력 프로그램을 넘어 계산 로직이 포함된 구조로 구현

- **시리얼 통신 인터페이스 프로토타입**
  - `jSerialComm` 라이브러리를 활용해 외부 장치와 연결 가능한 형태로 메서드 구성
  - 실제 하드웨어 제어까지는 진행하지 않았지만, 향후 확장 가능한 흐름을 코드 수준에서 설계

### 주요 파일

- `Cat_Feeding.java`
  - 프로그램 실행 진입점
  - 메뉴 기반 입력 흐름 제어
  - 급식량 계산, 데이터 저장/로드, 시리얼 통신 호출 담당

- `cat_data.txt`
  - 고양이 정보 저장용 로컬 데이터 파일
  - 프로그램 재실행 시 기존 데이터를 불러오는 데 사용

## 7. 트러블 슈팅

### 1) 짧은 개발 기간으로 검증 범위가 제한됨
약 1주 내에 완성해야 했던 단기 과제라, 전체 예외 케이스를 충분히 점검하지 못했습니다.  
우선은 기본 입력 흐름과 저장 기능이 동작하는 수준까지 구현하는 데 집중했습니다.

### 2) 시리얼 통신은 프로토타입 수준에 머무름
`jSerialComm` 기반 통신 메서드는 구성했지만, 실제 아두이노 장비를 연결해 물리적으로 검증하지는 못했습니다.  
따라서 이 부분은 완성 기능이라기보다, 외부 장치 제어를 염두에 둔 인터페이스 설계 단계에 가깝습니다.

### 3) 입력값 검증과 예외 처리 보완 필요
콘솔 기반 프로그램 특성상 잘못된 입력이나 경계값 처리에 대한 보완 여지가 남아 있습니다.  
이후 확장한다면 입력 유효성 검사와 예외 처리 구조를 먼저 정리할 필요가 있습니다.
