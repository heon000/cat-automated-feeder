# 자바 기반 고양이 자동 급식기 시스템 프로토타입 (Cat Automated Feeder)

2학년 2학기 '객체지향 프로그래밍' 강의에서 가산점 획득을 위해 수행한 자율 과제물로, 자바 언어를 활용해 구현한 텍스트 기반 자동 급식 제어 프로그램입니다. 

> 본 프로젝트는 취업 포트폴리오 관리를 위해 보고서의 소스코드를 기반으로 깃허브 레포지토리에 복원 및 이관한 프로젝트입니다. 단기간 내에 수행한 자율 과제로 아두이노 하드웨어와의 실제 물리적 연동은 진행하지 않았으며, AI의 도움을 받아 코드 수준에서 시리얼 통신 인터페이스를 모색하고 설계해보는 것에 의의를 두었습니다.

---

## 1. 프로젝트 소개
* **진행 기간:** 2024.12 (약 1주일, 단기 과제)
* **개발 배경 및 목적:** 실제 반려묘를 양육하면서 느낀 주기적이고 정밀한 사료 배식의 필요성을 바탕으로 기획되었습니다. 강의 시간에 배운 자바의 객체지향 기초 문법과 파일 입출력을 복습하고, 외부 라이브러리를 이용한 시리얼 통신 코드를 분석하여 소프트웨어 중심의 IoT 제어 흐름을 이해하고자 시작되었습니다.

---

## 2. 기술 스택
* **개발 언어:** Java (JDK 17)
* **운영체제 환경:** Windows 10 / 11
* **사용한 라이브러리:** jSerialComm (아두이노 시리얼 통신 인터페이스 제어용)

---

## 3. 시작 가이드 및 실행 방법

### 빌드 및 구동 환경
* 본 프로그램은 시리얼 포트 제어를 위해 Windows 운영체제 환경이 필요합니다.
* 고양이 데이터 저장을 위해 로컬 디렉터리에 파일 쓰기 권한이 필요합니다.

### 실행 방법 
1. 본 레포지토리의 소스코드를 다운로드합니다.
2. Java IDE(Eclipse 또는 IntelliJ)를 통해 프로젝트를 로드합니다.
3. Cat_Feeding.java 파일을 실행(Run)합니다.
4. 콘솔 창이 활성화되면 안내 메뉴(1~4번)에 따라 테스트를 진행합니다.

---

## 4. 개발 인원 및 역할
* **참여 인원:** 1인 개인 프로젝트
* **본인 역할 (이헌영):** 자율 과제 기획, 자바 기반 데이터 연산 로직 구현, 직렬화 파일 저장 시스템 구축 및 AI 툴을 활용한 시리얼 통신 데이터 송신 메서드 설계

---

## 5. 핵심 기능
* **자바 객체 직렬화(Serialization):** ObjectOutputStream 및 ObjectInputStream을 활용하여 프로그램이 종료되더라도 입력된 고양이의 정보 데이터(cat_data.txt)가 로컬 파일 시스템에 안전하게 저장되고 불러와지는 영속성을 구현했습니다.
* **적정 사료량 자동 연산 알고리즘:** 고양이의 체중을 기반으로 한 기초대사량 연산 수식인 Math.pow 구문을 활용하고, 활동 수준 가중치를 계산하여 하루에 필요한 적정 사료량을 유동적으로 도출합니다.
* **시리얼 통신 인터페이스 설계:** 향후 하드웨어 확장을 염두에 두고 jSerialComm 라이브러리의 포트 개방 및 바이트 스트림 출력 메서드를 활용하여, 배식 명령 발생 시 외부 디바이스로 데이터를 전달하는 통신 함수 프로토타입을 코드 레벨에서 구성했습니다.

---

## 6. 결과 및 성과
* **자율 과제 요구사항 충족:** 제한된 시간 내에 고양이 데이터 연산 로직 및 자바 직렬화 기반의 파일 저장 구조를 구현하여 과목 가산점 확보 성공.
* **프로토타입 범위 완수:** 최초 기획 단계의 아두이노 물리 연동까지는 도달하지 못했으나, 코드 레벨에서 통신 인터페이스 구조를 설계하고 콘솔 상에서 입력 제어 흐름을 검증하는 단기 프로토타입 목적 달성.

---

## 7. 구현 상의 한계점 및 아쉬운 점

### 1) 사용자 입력 유효성 검증 부재
* **문제점:** 콘솔 환경에서 고양이의 활동 수준(1~3 제한)을 입력받을 때, 실행 화면 기록과 같이 범위를 완전히 초과하는 숫자인 '22'를 입력하더라도 별도의 필터링이나 에러 메시지 없이 그대로 데이터 모델에 수용되는 결함이 존재합니다. 
* **한계점:** 단기간 내에 과제를 완수해야 하는 일정 제한으로 인해, 잘못된 사용자 입력에 대응하는 방어적 코드 조건을 꼼꼼하게 다듬지 못하고 기능 구동 중심으로 마무리지은 아쉬움이 있습니다.
* **현재 시점의 분석:** 데이터 입력 직후 유효 범위를 사전 검증하는 조건문 루프나 예외 처리 블록을 구축하여 잘못된 데이터의 인입을 원천 차단하는 설계가 보완되어야 함을 식별하고 있습니다.

### 2) 외부 라이브러리 및 AI 의존적 코드 구성 (물리 연동 미완수)
* **문제점:** 소스코드 내 시리얼 포트를 제어하는 `SerialPort` 관련 구문들은 실제 아두이노 하드웨어를 연결하여 물리적인 통신 테스트를 거친 것이 아닙니다. AI 툴과 통신 라이브러리 예제를 참고하여 코드 레벨에서 데이터 송신 프레임워크만 구성해 둔 상태입니다.
* **한계점:** 이로 인해 실제 물리 포트가 개방되고 닫히는 과정에서의 통신 지연이나 자원 해제의 예외 안정성에 대해 직접 하드웨어 덤프를 뜨며 검증하지 못한 한계가 있습니다.

---

## 8. 프로젝트를 통해 배운 점 및 개선점
* **객체지향 및 파일 I/O 개념 체득:** 자바 언어의 핵심인 클래스 모델링과 파일에 직접 데이터를 쓰고 읽는 직렬화 메커니즘을 직접 다루어 보며 백엔드 데이터 관리의 기초를 학습했습니다.
* **개선점 및 성장 빌드업:** 단기간 내에 프로토타입 기능을 구동하는 것에 집중하다 보니 예외 처리나 하드웨어 물리 연동을 완수하지 못한 아쉬움이 남는 프로젝트입니다. 향후 본 프로그램을 고도화한다면, 프로그램 내 입력값 유효성 검증 로직을 보완하여 전반적인 소프트웨어 안정성을 고도화하고, 실제로 아두이노 하드웨어 디바이스를 연결하여 물리적인 배식 제어 연동을 직접 수행해볼 계획입니다.
